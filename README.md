# App Legal Pages

Privacy policies for the mobile apps published by Jagat IT UK Ltd, one folder per app.

| App | Folder |
|---|---|
| GrowFocus | `growfocus/` |
| ShatterFocus | `shatterfocus/` |

Each folder holds a static `index.html`, linked from the app store listings. The older repos `growfocus-privacy` and `shatterfocus-privacy` stay live because existing store listings point to them.

## Add an app

1. Create `<app>/index.html` with the privacy policy.
2. Add a row to the table above.
3. Open a pull request.
